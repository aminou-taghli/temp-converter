# Temperature Converter 🌡️

A simple C program that converts temperature from Celsius to Fahrenheit.

## 🚀 Features
- Converts Celsius input to Fahrenheit.
- Fast, lightweight, and easy to run.

## 🛠️ How to Compile & Run

### Using Dev-C++ (Windows)
1. Open Dev-C++.
2. Go to `File` > `Open` and select `Celsius to Fahrenheit.cpp`.
3. Press `F11` (or click `Execute` > `Compile & Run`).
